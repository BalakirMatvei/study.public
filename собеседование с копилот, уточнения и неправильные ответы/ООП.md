# 🧩 2) Инкапсуляция — простыми словами

Инкапсуляция — это **скрытие внутреннего устройства объекта** и предоставление только нужного интерфейса.

В Python нет настоящей приватности, но есть соглашения:

- `_attribute` — защищённый (protected), не трогай без необходимости
    ыг
- `__attribute` — приватный (private), Python «прячет» его через name mangling
    

Пример:
```python
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance  # приватный атрибут

    def deposit(self, amount):
        self.__balance += amount

    def get_balance(self):
        return self.__balance
```

Зачем это нужно:

- чтобы защитить данные от случайного изменения
    
- чтобы управлять доступом через методы
    
- чтобы код был безопаснее и понятнее
    

# 🧩 3) Полиморфизм — простыми словами

Полиморфизм — это когда **разные объекты могут выполнять один и тот же метод по‑разному**.

Пример:
```python
class Dog:
    def sound(self):
        return "Woof"

class Cat:
    def sound(self):
        return "Meow"
```

Оба класса имеют метод `sound()`, но результат разный.

В Python полиморфизм работает благодаря **динамической типизации** — главное, чтобы у объекта был нужный метод.

# ✔ Как выглядел бы идеальный ответ на собеседовании

**Наследование** — позволяет одному классу получать атрибуты и методы другого. **Инкапсуляция** — скрывает внутренние данные и предоставляет безопасный интерфейс.
**Полиморфизм** — разные классы могут иметь одинаковые методы, но реализовывать их по‑разному.


>Класс — это шаблон, описывающий структуру и поведение объектов.
>Объект — экземпляр класса, созданный на его основе.
>Атрибут — данные, принадлежащие классу или объекту.
>Метод — функция внутри класса, описывающая действия объекта
