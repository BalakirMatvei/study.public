могут применяться для упрощения самого запроса или его логики

часто подзапросы можно убрать, переписав запрос с использованием ***join***,
но для выбора что использовать нужно рассматривать конкретные ситуации

```sql
select column_name1, column_name2
from table_name1
where culumn_name1 > (select max(column_name3) from table_name2) 
```
подзапрос записывается в скобках и может быть любым
```sql
select country, column_name2
from table_name1
where table_name1.country in (select country from table_name2) 
```
