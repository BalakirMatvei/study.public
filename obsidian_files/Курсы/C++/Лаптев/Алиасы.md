Синоним типа, заданный программистом
Их можно объявить 2мя способами:
Оператор "typedef":

Оператор(typedef) имя_типа синоним;

```c++
typedef double real;
```
Можно использовать несколько синонимов:
```c++
typedef char byte, small;
```

С помощью using:

Using синоним = тип;

```c++
using real = double;
```
