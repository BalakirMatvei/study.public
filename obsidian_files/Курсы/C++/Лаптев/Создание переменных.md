`const int number = 10;`
создает переменную "number" и присваивает ей значение 10

`const string name = "Matvei";`
создает переменную "name" и присваивает ей значение "Matvei"

В общем виде запись выглядит так:
`const variable_type variable_name = variable_value;`

Если я хочу в значение переменной передать и строки и переменные, то их можно соединить через "+":
```c++
const string greeting = "Hello, " + name + ' ' + surname;
```

Объявление переменных:(оператор объявления)
```c++
float х , у , z;
double а ;
long double v, w ;
```

Инициализация(присваивание значения) переменных:
```c++
float t = value;

double d (value);

long double dd {value};
```

!Позволяет обнулить переменную не указывая 0 в фигурных скобках:
`int k{};` - универсальная инициализация

В одном операторе объявления можно смешивать разные способы инициализации:
```c++
float a{1.1}, b (1.2) , с= 0.8;
```
Однако лучше так не делать и всегда инициализировать переменные одним и тем же способом.

Инициализация переменной через другую переменную:
```c++
int a{2}, b(a), c = b 
```

Вместо переменной можно объявить поименованную константу:
```c++
const double pi = 3,1415
double const exp = 2.71828
```
слово "const" можно писать как до типа, так и после

Вместо слова "const" можно писать"constexpr".

Если тип переменной известен заранее, то ее можно объявить через зарезервированное слово "auto"
```c++
auto variable_name1 {8.7};      // double
auto variable_name1 = 1.2F;    //float
auto const variable_name1 {2.2L} //long double
costexpr auto variable_name {8}; //int
auto Length {18'000'000'000uLL} ; //unsigned long long  
```
