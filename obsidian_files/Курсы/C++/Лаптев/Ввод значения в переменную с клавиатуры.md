(аналог input в python)
`cin >> variable_name`

В c++, в отличии от python нельзя ввести с клавиатуры несколько слов разделенных пробелом(например имя и фамилию)
поэтому для задания с клавиатуры нескольких слов можно делать так:
```c++
string name;
string surname;
cin >> name >> surname
```
Тогда первое слово пойдет в первую переменную(name), а второе во вторую переменную(surname).

Это можно заменить на 2 ввода(ввод заканчивается при нажатии клавиши Enter)
```c++
cin >> name
cin >> surname
```
