Позволяет устанавливать точность(кол-во знаков после запятой в вещественном числе) для числа при выводе.
Для его использования нужно подключить библиотеку `<iomanip>`
```c++
#include <iomanip>

int main(){
	cout << "площадь - " << setprecision(n) << S << endl;
}
```
где n - кол-во знаков после запятой
