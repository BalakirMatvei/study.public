```c++
int main()
{
	cout << "Hello world" << endl;
	return 0;
}
```
main - название функции, которая должна быть в каждой программе(причем единственная)
int - "обещанный" тип данных, который вернет функция
cout и endl - оператор вывода
return - оператор возврата
0 - целая константа(литерал)(0 - общепринятый цело-численный литерал обозначающий нормальное завершение программы)
"Hello world" - строковый литерал
