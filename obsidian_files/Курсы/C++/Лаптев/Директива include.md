Это директива процессора.

Средства ввода и вывода, средства для работы со строками и тд
уже давно перестали включать в язык программирования "из коробки", в python библиотеки импортируются с помощью `import`,
а в c++ с помощью директивы include(`#include`)

Что бы в программе использовать те или иные средства подключают стандартную библиотеку c++(STL - Standart Template Library) с помощью строчки:
`#include <iostream>` 
iostream - input output stream - средство потокового ввода/вывода

`<iostream>` - аргумент директивы, который задан в угловых скобках(<>). Эти скобки - признак стандартного заголовка.
