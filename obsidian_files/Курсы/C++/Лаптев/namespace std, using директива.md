строка `using namespace std;`(using директива) не является обязательной, но без нее не получится вывести что либо на экран, тк компилятор выдаст ошибку на словах "cout" и "endl". Если не прописать эту строку, то перед каждым специальным словом нужно будет ставить "std::"

например:
`std::cout << "Hello world" << std::endl;`
 Вместо
 `cout << "Hello world" << endl;`
