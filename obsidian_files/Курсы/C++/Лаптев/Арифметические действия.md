"+" - сложение, 
"-" - вычитание, 
"*" - умножение,
"/" - деление,
"%" - остаток от деления

при делении целого на целое дробная часть(при налии) отбрасывается
```c++
5 / 2 = 2
```
но если хотя бы 1 из них будет вещественным, то и ответ будет вещественным
```c++
5.0 / 2 = 2.5
5 / 2.0 = 2.5
```

Так же можно(как в python) использовать запись вида:
```c++
variable_name += 1
variable_name -= 1
variable_name *= 1
variable_name /= 1
```

Если нужно прибавить или отнять единицу от переменной, то:
```c++
++x

--x
```
если нужно увеличить/уменьшить переменуную на 2, то:
```c++
++++x

----x
```

Но
```c++
d = x++
d = x--
```
сначала значение х попадает в переменную "d", а потом меняет свое значение(+ или - 1)(При такой записи не получится увеличить/уменьшить на 2 используя 4 знака +/-)
