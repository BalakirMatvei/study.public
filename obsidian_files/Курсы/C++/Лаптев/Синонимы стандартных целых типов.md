Для их использования нужно подключить стандартную библиотеку 
`#include <cctype>` - Более старая(унаследована от С)
``#include <cstdint>`- Более новая(с C++11)(лучше использовать ее)

Синонимы:
```c++
int8_t v_name1; //signed char
int16_t v_name2; //signed short
int32_t v_name3; //signed int
int64_t v_name4; //signed long long

uint8_t v_name5; //unsigned char
uint16_t v_name5; //unsigned short
uint32_t v_name5; //unsigned int
uint64_t v_name5; //unsigned long long
```
