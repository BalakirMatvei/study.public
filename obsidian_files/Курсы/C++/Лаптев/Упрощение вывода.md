вместо 3 отдельно выведенных строк:
```c++
int main()
{
    cout << "+-----------+" << endl;
	cout << "|Hello world|" << endl;
	cout << "+-----------+" << endl;
	return 0;
}
```
можно убрать некоторые "cout" и ";":
```c++
int main()
{
    cout << "+-----------+" << endl
	     << "|Hello world|" << endl
		 << "+-----------+" << endl;
	return 0;
}
```

Можно еще упростить используя специальные символы([[Экранирование символов]])
```c++
int main()
{
    cout << "+-----------+\n"
	     << "|Hello world|\n"
		 << "+-----------+\n";
	return 0;
}
```
