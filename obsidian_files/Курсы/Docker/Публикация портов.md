`docker run -p external_port:interior_port image_name`
external - внешний, interior - внутренний порт контейнера

Пример:
`docker run -d -p 8080:80 nginx`

После этого можно ввести в браузере "localhost:external_port"(localhost:8080) и попасть на страницу образа запущеного в контейнере

Для разных контейнеров должны быть использованы разные порты(например 8080 и 8081)
