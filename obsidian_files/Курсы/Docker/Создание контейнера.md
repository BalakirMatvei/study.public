`docker run image_name` - Создает контейнер по образу image_name, если локально такого образа нет, то он скачивается с DockerHub и запускается

`docker pull image_name` - Скачивает образ image_name с  Docker Hub 

`docker rm image_id/image_name` - Удаляет завершенный контейнер из списка, который появляется после команды `docker ps -a`, для удаления надо ввести id или имя контейнера

 если к команде `docker run image_name` добавить "-i" и "-t"(можно "-it")(i - интерактивный, t - терминал) перед "image_name", то для процесса откроет интерактивный терминал(полезно например для процесса "busybox"(запускает оболочку sh)) 

Внутри контейнера есть доступ в интернет.

что бы завершить процесс внутри контейнера можно использовать команду:
`docker stop image_name`

Что бы удалить все остановленные контейнеры можно использовать команду:
`docker container prune`

Если в контейнере нет активного процесса, то докер его останавливает. 

`docker run -d image_name` - создает контейнер в фоновом режиме 

`docker run -d --name custom_name image_name` - создает контейнер по image_name c пользовательским именем custom_name
