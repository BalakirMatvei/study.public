```ssh
docker run image_name
```
Создает контейнер по образу image_name

```ssh
docker pull image_name
```
Скачивает образ image_name с  Docker Hub 

```ssh
docker rm image_id/image_name
```
Удаляет завершенный контейнер из списка, который появляется после команды `docker ps -a`, для удаления надо ввести id или имя контейнера
