`docker version` - показывает версию клиента и сервера docker

`docker ps -a` - показывает список всех запущеных и остановленых контейнеров(без -a будут видимы только запущеные контейнеры)

`docker images` - показывает список образов, которые находятся локально на компьютере

`docker container inspect container_id/name` - выводит всю информацию о запущеном контейнере(ip, gateway, etc)

`docker stop container_id` - останавливает контейнер
`docker kill container_id` - принудительно и моментально останавливает контейнер

`docker exec -it container_id/name process_name` - запускает процесс process_name в уже запущеном контейнере(-it - интерактивный терминал(опционально))(подключает локальный терминал к процессу внутри контейнера)

Если нужно удалять контейнер из списка `docker ps -a` после остановки контейнера, то можно добавить опцию "--rm" при создании контейнера:
`docker run --rm image_name`
после остановки контейнер будет удален.

Если команда слишком длинная, то ее можно разбить на несколько строк используя обратный слэш(рекомендуется каждое действие переносить на новую строку)
```
docker run \
--name my_image_name \
-v ${PWD}:path \
-d \
--rm \
image_name
```
