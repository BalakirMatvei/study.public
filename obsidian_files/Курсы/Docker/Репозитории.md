В репозиториии хранятся версии образа(одного и того же). 
У каждой версии могут быть свои теги.
например:
1.1 / latest / 7.4 / 5.6.4
Так же у одной версии может быть несколько тегов.

Теги:
latest -  последняя версия
alpine - самая маленькая по размеру версия образа

Репозитории можно сохранять локально у себя на пк или хранить их на любом реесте репозиториев(например DockerHub)
