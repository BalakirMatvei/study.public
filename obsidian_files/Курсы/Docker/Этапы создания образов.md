- создать Dockerfile
- положить его в корне папки приложения(для которого нужно создавать свой образ)
- Dockerfile содержит инструкции по созданию образа
- При создании образа можно указать ему имя или тег(если этого не сделать, то docker сам создаст ему тег)
- на основании готового образа можно создавать контейнеры

```
FROM python:alpine
WORKDIR /app
COPY . .
CMD ["python", "main.py"]
```
В первой строке выбирается базовый образ(python) по подобию которого будет создаваться наш образ, и указывается его тег(alpine)

Во второй строке после команды WORKDIR указывается рабочая директория, в которой будет лежать наш образ

В третьей строке копируются нужные файлы в рабочую директорию

В четвертой строке указывается процесс(python), который будет запущен в контейнере, созданном по этому образу. и файл, который будет запущен(main.py)

`docker build path_to_dockerfile `
После запуска этой команды docker найдет dockerfile(Если его название отличается от "dockerfile", то надо указать опцию -f) и выполнит все инструкции из него
Если надо указать собственное название и тег для нового образа, то:
```
`docker build path_to_dockerfile -t image_name:image_tag
```
