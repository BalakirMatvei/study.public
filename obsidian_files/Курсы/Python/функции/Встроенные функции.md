**ОПЕРАЦИИ НАД ЧИСЛАМИ**
```python

```
**ЛОГИЧЕСКИЕ ОПЕРАЦИИ**
```python
all([1, 2, ''])#проверяет все ли элементы массива True
any([1, 2, ''])#проверяет есть ли хоть один элемент массива возвращающий True
```
**ИНТРОСПЕКЦИЯ**
```python
dir([])#выдаст список всех атрибутов объекта лист
help([])#выдаст более подробный мануал по атрибутам объекта
id()#возвращает айди любого объекта, переданного в качестве аргумента
```
