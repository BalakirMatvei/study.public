Если переменные объявлены не в теле функции, а просто в модуле, то эти переменные принадлежат глобальному пространству имен("global namespace")(своё для каждого модуля)

Пространство имен(namespace) - набор связей имен с объектами(под капотом - словарь)
 
Функции могут использовать переменные из global namespace,
но не наоборот:
```python
a, b = 1, 2

def example1():
	print(a+b)#правильно
```
```python
def example2():
	c, d = 3, 4
	pass

print(c + d)#неправильно
```

В ветвлениях **!не рекомендуется!** инициализировать переменные в одной из веток:
```python
a = 0
if a > 2:
	b, c = 2, 3
else:
	pass

print(b+c)
```
тк если интерпритатор не попадет в эту ветку, то он выдаст ошибку(неизвестные переменные)
Так что **следует** либо указывать значения для переменных во всех ветках
```python
a = 0
if a > 2:
	b, c = 2, 3
else:
	b, c = 4, 5

print(b+c)
```
либо инициализировать их **до ветвления**, а в нем только их изменять
```python
a = 0
b, c = None, None
if a > 2:
	b, c = 2, 3
else:
	b, c = 4, 5

print(b+c)
```

Для удобства можно в начале имени локальных перемнных ставить нижнее подчеркивание
```python
a, b = 1, 2

def example():
	_a, _b = 3, 4
	print(_a + _b)

example()#7
```

Если переменной нет в локальном namespace, то она берется из глобального
```python
a = 3, b = 4
def example():
	b = 6
	print(a + b)#а = 3(из global), b = 6(из local)
	
exapmle()#вывод:9
print(a + b)#вывод:7
```

Если переменная хоть раз объявлена внутри функции, то она считается локальной. т.е.:
```python
a = 1

def example():
	print(a)#выдаст ошибку
	a = 9
	print(a)
```
первый принт выдаст ошибку, тк переменная а переназначается внутри функции, т.е. считается локальной, **но  для интерпритатора на момент первого принта она не объявлена, тк это будет сделано в следующей строке**  

Можно добавлять/удалять/изменять значения переменных из другого модуля
Добавление:
```python
#module1
x = "Globo"

#module2
module1.y = "New name"
print(module1.y)#"New name"
```
Удаление:
```python
#module1
x = "Globo"

#module2
del module1.x
```
Изменение:
```python
#module1
x = "Globo"

#module2
module1.x = "New x name"
print(module1.x)#"New x name"
```
**Все эти изменения сохраняются только для текущего запуска программы, в исходниках ничего не меняется**(Это называют Monkey patch)

Оператор `global`
```python
function():
	global x
	x = 'Loco'
	print('in function1 x =', x)
	
function()#'in function1 x = Loco'
print(x)#'Loco'
```
После вызова функции переменная "x" будет помещена в глобальный namespace(если попытаться вывести x до вызова функции, то пайтон выдаст ошибку "x is not defined") 

Функция globals():
```python
print(globals())
```
Выдаст словарь глобального namespace(ключ - имя объекта, значение - содержимое объекта)

Функция locals():
```python
print(locals())
```
Выдаст словарь локального namespace(ключ - имя объекта, значение - содержимое объекта)
