Позиционные параметры можно распаковать из списка:
```python
ls = [1, 2, 3]
def example(x, y, z):
	return x**2 + y**2 + z**2

res = exaple(*ls)
```
Тогда присвоятся следующие параметры "x = 1, y = 2, z = 3"

Именованные параметры можно распаковать из словаря:
```python
diction = {'x' : 1, 'y' : 2, 'z' : 3}
def example(x, y, z):
	return x**2 + y**2 + z**2

res = exaple(**ls)
```

При этом способе **важно**, что бы количество элементов списка/словаря совпадало с количеством принимаемых функцией параметров.

Можно совмещать:
```python
some_list = [2, 3]
some_dict = {'z' : 4}#можно было написать dict(z=4)

def example(x, y, z):
	return x**2 + y**2 + z**2
	
res = example(*some_list, **some_dict)
```
```python
res = example(2, *some_list)
```
