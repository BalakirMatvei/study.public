**Обе являются суперфункциями**
****
**map()**
Принимает 2 параметра(при передаче нескольких параметров в функцию(первый параметр `map`) можно передавать несколько масиивов)
- функцию-обработчик
- итерируемый объект
Поочередно применяет функцию-обработчик к каждому элементу.
```python
def mul_by_2(x):
	return x * 2
	
res = map(mul_by_2, range(10))
print(list(res))
```

```python
numbers1 = [1, 2, 3, 4, 5]
numbers2 = [6, 7, 8, 9, 10]
res = map(lambda x, y: x + y, numbers1, numbers2)
```
****
**filter()**
Принимает 2 параметра
- функцию-фильтр
- итерируемый объект
Поочередно применяет функцию-фильтр к каждому элементу, если элемент возвращает `True`, то он попадает в итоговую выборку
```python
def nechet(x):
	return x % 2
	
res = filter(nechet, range(10))
print(list(res))
```
****
**Обе возвращают генератор(оберни в list, что бы получить список).**
****
Можно комбинировать их:
```python
def mul_by_2(x):
	return x * 2
	
def nechet(x):
	return x % 2
	
res = map(mul_by_2, filter(nechet, range(10)))
print(list(res))
#вывод:
#[2, 6, 10, 14, 18]
```
