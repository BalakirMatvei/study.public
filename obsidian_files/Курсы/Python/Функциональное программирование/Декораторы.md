Декоратор - функция высшего порядка, которая принимает другую функцию (или метод) в качестве аргумента, расширяет или изменяет её поведение и возвращает новую функцию.
****
Пример:
![[Pasted image 20261113175824.png|579]]
`time_track` "отдекорировала" функцию `digit`(изменила ее работу)
****
Для декораторов есть синтаксический сахар:
![[Pasted image 20261113180253.png|576]]
Строка `@time_track` заменяет строку 
`digits = time_track(digits)`

Эта строка обозначает: функция `digits` будет "отдекорирована" функцией `time_track` и будет сохранена в области видимости под тем же именем `digits`.
****
Минусы декораторов:
- Затруднена отладка
- Нужны определенные действия, что бы сохранить атрибуты декорируемой функции.
