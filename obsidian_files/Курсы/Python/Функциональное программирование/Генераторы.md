Что бы создать генератор
![[Pasted image 20261113192946.png]]
в функции должен быть использован оператор `yield`.

`yield` возвращает что то из функции, но в отличии от `return` не останавливает ее работу, а **приостанавливает**(делает ее ленивой), при следующем вызове она продолжит выполнение с того же места, с теми же локальными переменными(и глобальными, которые используются в этой функции).

Поэтому оператор `yield` прописывается раньше действий над переменными, что бы после возврата в функцию они выполнились сразу.

Пример(вычисление ряда Фибоначчи):
![[Pasted image 20261113194311.png|411]]
После каждого вызова функции в цикле интерпритатор заходит в функцию и дойдя до оператора `yield` возвращает значение `a` и выходит, заморозив функцию на том месте.
****
***По генератору можно пройти только 1 раз****, поэтому после выполнения блока кода на скриншоте нельзя написать проверку.[[Итераторы#^4c84a8]]
```python
print(13 in f)
```
т.к. это подразумевает проход по генератору еще раз.
Так что для этого придется создать еще 1 генератор:
```python
f2 = fibonacci(n=10)
print(13 in f2)
```
****
Можно сделать бесконечный генератор
```python
def fibonacci():  
    a, b = 0, 1  
    while True:  
        yield a  
        a, b = b, a+b
        
for value in fibonacci():
	print(value)
	if value > 10 ** 6:
		break
```
Но тогда нужно вне функции контролировать её вызов, что бы не получить бесконечный цикл.
****
**НО** можно это контролировать и внутри функции-генератора с помощью оператора `return`.
Он эквивалентен `raise StopIteration` и для воспринимается как завершение итерации:
```python
def fibonacci():  
    a, b = 0, 1  
    while True:  
        yield a  
        a, b = b, a+b
        if value > 10 ** 6:
			return
        
for value in fibonacci():
	print(value)
```
Можно с оператором `return` вернуть что либо, но оно попадает в аргументы исключения `StopIteration` и практически не видно снаружи в коде.[[Исключения#^1c7e5e]] 
****
Еще одно применение генераторов - остановка вложенных циклов
```python
list1 = [2, 3, 4, 5]
list2 = [6, 7, 8, 9]
to_find = 32
def next_mult(l1, l2):
	for x in l1:
		for y in l2:
			yield x, y, x*y

for x, y, res in next_mult(list1, list2):
	print(x, y, res)
	if res == to_find:
		print('Found!')
		break
```
при нахождении нужного значения генератор просто останется в замороженном состоянии(=> циклы прерваны сразу по нахождении нужного значения).

Это полезно т.к. если прописывать оператор `break` во внутреннем цикле, то будет прерван только он и потом начнется новая итерация внешнего цикла.
****
Генератор может принимать новые значения извне с помощью оператора `send`
```python
f = gener()
name = f.send('Sasha')
```
Но что бы генератор мог принять это в нем должна быть такая конструкция:
```python
def gener():
	new_value = (yield next)
```
