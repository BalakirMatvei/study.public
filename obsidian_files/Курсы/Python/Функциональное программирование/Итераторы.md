***Итератор*** - **либо** объект созданный функцией `iter()`(в скобках нужно передать итерируемый объект), **либо**  объект класса, в котором определены методы `__iter__()` и `__next__()`.
****
Созданный функцией `iter()`:
```python
nums = [1, 2, 3, 4, 5]
it = iter(nums)
print(it)
print(next(it))
```

- Итератор - просто питоновский объект
- Получить следующий элемент итератора можно с помощью `next()`
- Итератор помнит, какой элемент нужно выдать следующим, так что можно получать из него следующий элемент в любой удобный момент выполнения программы
- Если после того, как итератор выдаст все свои значения попробовать еще раз вызвать `next()`, то python выдаст ошибку

Итератор занимается "**ленивыми вычислениями**", т.е. он вычисляет следующее значение последовательности по требованию.
Полезно, когда нужно вычислить огромный массив данных и найти конкретный элемент. Что бы не занимать лишнюю память и ресурсы процессора используют итераторы.

Если задать проверку наличия числа в итераторе: ^4c84a8
```python
class Fibb:
	def __init__(self, n):
		self.i, self.a, self.b, self.n = 0, 0, 1, n
		
	def __iter__(self):
		self.i, self.a, self.b = 0, 0, 1
		return self
		
	def __next__(self):
		self.i += 1
		if self.i > 1:
			if self.i > self.n:
				raise StopIteration
			self.a, self.b = self.b, self.a + self.b
		return self.a
	
	
fib_iterator = Fibb(123)
print(13 in fib_iterator)
```
то итератор будет считать значения, пока не найдет нужное число
