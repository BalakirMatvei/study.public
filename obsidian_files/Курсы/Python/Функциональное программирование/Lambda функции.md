Маленькие одноразовые функции, для которых использовать `def` не целесообразно.
```python
lst = [1, 2, 3, 4, 5]
lst = map(lambda x: x * 2, lst)
#вывод [2, 4, 6, 8, 10]
```
****
Общий вид `lambda` функции:
`lambda аргумент : действие с аргументом` 
По сути после двоеточия стоит `return`, но в `lambda` функциях его писать не надо.
****
Она может принимать несколько аргументов:
```python
numbers1 = [1, 2, 3, 4, 5]
numbers2 = [6, 7, 8, 9, 10]
res = map(lambda x, y: x + y, numbers1, numbers2)
```
****
`lambda` функция создается в момент выполнения кода, а не "компиляции", так что она может замедлять код.
****
Не нужно создавать слишком обширные `lambda` функции, если в ней больше 3-5 операторов, то лучше создать функцию через `def`.
