Можно написать функцию, которая будет создавать и возвращать новую функцию:
```python
def get_multi(n):
	if n == 2:
		def multiplier(x):
			return x * 2
	elif n == 3:
		def multiplier(x):
			return x * 3
	else:
		raise Exception('I can make multipliers only 2 and 3')
	return multiplier
		
by_2 = get_multi(2)
by_3 = get_multi(3)
```
Можно создать функцию-умножитель на любое число:
```python
def get_multi(n):

	def multiplier(x):
		return x * n
		
	return multiplier
```
При такой записи внутренняя функция запоминает внутри себя параметры, переданные внешней(родительской) функции при ее вызове.
Это так называемое **замыкание** - объект функции хранит у себя все необходимые ему переменные в области видимости, точнее ссылки на них.
****
Нужно стараться **как можно меньше использовать изменяемые объекты и глобальные переменные внутри "функций на лету"**, это может привести к неожиданным последствиям.
Замыкать **объекты, созданные в области видимости внешней(родительской) функции можно**.
****
Еще один способ создания функции на лету это создать ее как объект:
```python
class Multiplier:
	
	def __init__(self, n):
		self.n = n
	
	def __call__(self, x):
		return self.n * x
		
nums = [1, 2, 3, 4, 5]
by_10 = Multiplier(n=10)
print(by_10(x=20))#вывод - 200
res = map(by_10, nums)
print(list(res))#вывод - [10, 20, 30, 40, 50]
```
Метод `__call__ ` вызывается если объект пытаются вызвать(как функцию) с помощью скобок:
`obj()`

Функция `callable()` проверяет можно ли вызвать то, что в нее передали(возвращает `Boolian`)
