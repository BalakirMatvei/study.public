В функциональном программировании **функции** используются **как объекты**.
***Если после имени функции не поставить скобки, то с ней можно работать почти как с обычной переменной***
***(присваивать в другие переменные, передавать как параметры в другие функции, добавлять в список)***
****
**Имя функции** указывает на объект функции.
```python
def some_func():
	pass
	
print(type(some_func))
#вывод: <class 'function'>
```
****
Можно обращаться к атрибутам функции:
```python
print(some_func.__name__)
```

Можно добавить еще ссылку на функцию:
```python
def some_func():
	pass
	
new_name = some_func
print(new_name())#выполнится вызов функции some_func
#но
print(new_name.__name__)
#вывод: some_func
#имя остается неизменным, таким как при определении 
```
****
Можно сделать список фунций, итерировать по нему, и вызывать их:
```python
def func1():  
    return list(range(10))  
  
  
def func2():  
    return ['math', 'PE', 'English']  
  
  
list_of_funcs = [func1, func2]  
for func in list_of_funcs:  
    print(func())
```
****
Можно передавать как параметры другим функциям:
```python
def func2():  
    return ['math', 'PE', 'English'] 

def func3(message, name_getter):
	print(message, name_getter())
	
func3(message='school subjects:', name_getter=func2)
```

**Функция высшего порядка - функция, которая  принимает на вход другие функции**
****
Функции могут быть значениями в словаре:
```python
dict_of_funcs = {
	'school subjects' : func2,
	'list of nums' : func1}
```
