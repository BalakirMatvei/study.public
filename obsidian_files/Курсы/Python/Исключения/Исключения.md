Что бы предотвратить падение(прекращение работы из-за ошибки) программы используют ключевые слова `try` и `except`:
```python
try:
	i = 0
	print(10 / i)
	print('Done!')
except:
	print("You cannot divide by zero")
```
Блок `except` срабатывает если в течении выполнения блока `try` случается ошибка.
В этом примере после `except` не указана никакая ошибка, это считается плохим стилем, тк python тогда ловит вообще все ошибки.

Лучше отлавливать конкретную ошибку:
```python
try:
	i = 0
	print(10 / i)
	print('Done!')
except ZeroDivisionError:
	print("You cannot divide by zero")
```
****
Если обработка нескольких ошибок одинакова, то можно их указывать вместе:
```python
try:
	c = a + b
except (ZeroDivisionError, NameError):
	print('что-то пошло не так...')
```
****
Если разные ошибки обрабатываются по-разному, то можно сколько угодно раз писать блок `except`
```python
try:
	i = 0
	print(10 / i)
	print('Done!')
except ZeroDivisionError:
	print("You cannot divide by zero")
except NameError:
	print("There's no such variables")
```
****
Можно для ошибки сделать псевдоним:
```python
try:
	i = 0
	print(10 / i)
	print('Done!')
except ZeroDivisionError as exc:
	print(f"smth went wrong, {exc}")
```
Псевдоним можно давать сразу нескольким ошибкам:
```python
try:
	c = a + b
except (ZeroDivisionError, NameError) as exc:
	print(f'что-то пошло не так..., {exc}')
```
В переменную `exc` попадет ошибка, которую отловит программа.
****
Иногда вместе с ошибкой прилетают и ее параметры: ^1c7e5e
```python
try:
	c = a + b
except (ZeroDivisionError, NameError) as exc:
	print(f'что-то пошло не так..., {exc}, параметры - {exc.args}')
```
