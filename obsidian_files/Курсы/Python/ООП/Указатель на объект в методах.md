```python
class Backpack:
	
	def add(self, item):
		print("В рюкзак положили", item)
		self.content = item

my_backpack = Backpack()
```
Будем работать с этим методом.

Вызов метода `add` 
```python
my_backpack.add(item='book')
```
Эквивалентен вызову:
```python
Backpack.add(self=my_backpack, item='book')
```
Просто во втором случае обращение к методу идет через класс, а не через конкретный объект => параметр `self` не заполняется автоматически.
