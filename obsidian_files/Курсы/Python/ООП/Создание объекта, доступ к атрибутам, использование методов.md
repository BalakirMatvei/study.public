**Можно сказать, что класс - шаблон для создания объектов**
(имея 1 класс можно создать сколько угодно объектов)

Что бы создать объект его нужно положить в переменную
```python
class Car:
	pass
	
my_car = Car()
```
Общая структура
Имя переменной = Имя класса()

Что бы достать конкретный атрибут объекта нужно указать его через точку:
```python
print(my_car.color)#red
```

Методы - функции определенные в классе(действия объекта)
Они тоже вызываются через точку, но со скобками в конце(функции все таки)
```python
my_car.start()
```

Имена классов принято писать в "camel" стиле(Все слова слитно, но каждое с большой буквы) 
```python
class ClassName():
	pass
```

Синтаксис класса:
```python
class Car:

	def __init__(self):
		self.color = 'red'
		self.price = 10000000
		self.max_speed = 250
		self.engine_rpm = 0
		
	def start(self):
		print('engine start')
		self.engine_rpm = 1000
```
В методе `__init__` (инициализация объекта) показаны атрибуты, которые будут присвоены объекту при создании
`self` обозначает тот объект, через которого будет обращение к методу(self - сам)

Методы написанные разработчиком тоже принимают `self` и  могут менять атрибуты(их значения) конкретного объекта(через который вызывался метод)

объект можно "создать" присвоением в переменную другого объекта
```python
car1 = Car()

car2 = car1
```
На самом деле это просто добавление еще одной ссылки на тот же объект.
```python
print(car1 is car2)#True
```

Атрибуты конкретного объекта можно менять:
```python
car1.color = 'black'
```
**Если на объект ведут 2 ссылки, то атрибуты можно менять используя любую из них**
