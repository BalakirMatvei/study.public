Инкапсуляция - сокрытие некоторых атрибутов
```python
class Parent:
	class_var1 = 1
	_class_var2 = 2
	__class_var3 = 3
	
	def __init__(self):
		self.var1 = 4
		self._var2 = 5
		self.__var3 = 6
		
	def parent_method(self):
		print(self.class_var1)#1
		print(self._class_var2)#2
		print(self.__class_var3)#3
		print(self.var1)#4
		print(self._var2)#5
		print(self.__var3)#6
		
class Child(Parent):
	def method(self):
		print(self.class_var1)#1
		print(self._class_var2)#2
		print(self.__class_var3)#3
		print(self.var1)#4
		print(self._var2)#5
		print(self.__var3)#6
```
Если создать объект класса `Child` и вызвать для него методы
`parent_method` и `method`, то
```python
obj = Child()
print(obj.parent_method())
print(obj.method())
```
первый принт выполнится нормально, а второй выдаст ошибку
![[Pasted image 20261031180059.png]]
тк если переменная начинается с двух подчеркиваний, то к нему в начало добавляется название класса, т.е. 
```python
__var3 = _Child__var3#если я вызываю его через объект класса Child
```
Эти записи эквивалентны
А атрибут `_Child__var3` не определен, так что выдает ошибку.

**Т.е. объекты подкласса имеют доступ ко всем атрибутам родительского класса, кроме тех, которые начинаются с двойного подчеркивания**
