Для конкретных классов можно переопределять атрибут или метод.
**Переопределение атрибута**
```python
class Pet:
	legs = 4
	
	def __init__(self, name):
		self.name = name
		
class Spider(Pet):
	legs = 8
```

**Переопределение метода**
```python
class Robot:
	def __init__(self, model):
		self.model = model
		
	def purpose(self):
		print('robot helps people')	
		
class WarRobot(Robot):
	
	def purpose(self):
		print('robot kills enemies')	
```

При вызове атрибута или метода он ищется по снизу вверх по иерархии наследования
