Атрибуты могут быть не только у объекта, но и у класса
```python
class Giraffe:
	total = 0
	
	def __init__(self):
		Giraffe.total += 1
```
Класс сам будет считать количество созданных объектов

Атрибутом класса можно передать что угодно:
```python
from random import choice

class Giraffe:
	total = 0
	neck_length = 6
	names = ['Mary', 'Jane', 'Chris', 'Jake', 'Milly']
	
	def __init__(self):
		Giraffe.total += 1
		self.name = choice(Giraffe.names)
```

Обращаться к ним надо через:
`Класс.атрибут`

Но так же можно через self
```python
print(self.neck_length)
```
Но, если у объекта есть личный атрибут`neck_length`, то будет вызван он, если нет, то этот атрибут будет искаться в пространстве имен класса.
Атрибут объекта перекрывает(главнее) атрибут класса.
