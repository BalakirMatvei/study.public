Необходимо, когда объекты нового класса должны сочетать в себе несколько "ролей"/"качеств"
```python
class Parent:
	def children(self):
		return ['Sasha', 'Arina']
		
class Emploee:
	def salary(self):
		return 1234567

class Man(Parent, Emploee):
	pass
	
man = Man()
print(man.children)#['Sasha', 'Arina']
print(man.salary)#1234567
```
Можно определять свои атрибуты и методы в дочернем классе.

Объект такого дочернего класса имеет доступ к методам родительских классов.

Если метод опеределен в обоих родительских классах(например `__str__`), то поиск происходит так:
1. сам дочерний класс
2. класс который первым написан в скобках при наследовании
3. второй в скобках и т.д.

```python
class GrandParent:
	pass

class Parent1(GrandParent):
	pass

class Parent2(GrandParent):
	pass

class Child(Parent1, Parent2)
	pass

obj = Child()
print(obj.__class__.__mro__)
```
`mro` - method resolution order
показывает в каком порядке будут искаться методы ^8acb4a

При множественном наследовании можно прописать `super().__init__()` в методах  `__init__(self)`базовых классов, тогда объект получит их атрибуты без своего метода-конструктора(или в дочернем классе в методе init тоже надо прописать `super().__init__()` )
![[Pasted image 20261101112021.png]]

```python
class Robot:
	def __init__(self, model):
		super().__init__()
		self.model = model
		
class CanFly:
	def __init__(self):
		super().__init__()
		
		
class Drone(Robot, CanFly):
	pass
	
	
drone1 = Drone(model="RJX-234")
```
Все работает, но если поменять классы в скобках местами при наследовании, то интерпритатор выдаст ошибку
![[Pasted image 20261101112721.png]]
Что бы это исправить нужно в обоих родительских классах принимать дополнительно `*args` и `**kwargs` и передавать их в базовый класс:
```python
class Robot:
	def __init__(self, model, *args, **kwargs):
		super().__init__(*args, **kwargs)
		self.model = model
		
class CanFly:
	def __init__(self, *args, **kwargs):
		super().__init__(*args, **kwargs)
		
		
class Drone(CanFly, Robot):
	pass
	
	
drone1 = Drone(model="RJX-234")
```
При таком способе можно менять наследуемые классы в скобках как хотим, параметры дойдут в свои классы.
