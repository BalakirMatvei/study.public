Специальные методы для эмуляции операций:
```python
object.__eq__(self, other)#Равенство(==)

object.__ne__(self, other)#Неравенство(!=)

object.__lt__(self, other)#Строго меньше(<)

object.__le__(self, other)#Меньше или равно(<=)

object.__gt__(self, other)#Строго больше(>)

object.__ge__(self, other)#Больше или равно(>=)
```
Они должны возвращать  тип `boolean` - `True/False`

Если в начало названия каждого из методов добавить "i":
```python
object.__iadd__(self, other)# += , а не +

object.__isub__(self, other)# -= , а не -
```
то они изменяют исходный объект, а не создают новый.

Если эти методы не определены в классе, то интерпритатор выдаст ошибку.

Не обязательно возвращать объект того же класса
```python
class Bread:
	
	def __str__(self):
		return "хлеб"
		
	def __add__(self, other):
		return Buter(part1=self, part2=other)
		
class Sausage:
	
	def __str__(self):
		return "колбаса"
		
	def __add__(self, other):
		return Buter(part1=self, part2=other)
		
class Buter:

	def __init__(self, part1, part2):
		self.part1 = part1
		self.part2 = part2
		
	def __str__(self):
		return f"я бутер из {self.part1} и {self.part2}"
```
Метод будет возвращать объект нового класса.
