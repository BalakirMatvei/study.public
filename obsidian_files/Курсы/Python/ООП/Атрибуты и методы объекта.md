Атрибут можно присвоить объекту не прописывая его в конструкторе(методе `__init__`)
```python
class Robot:
	
	def __init__(self):
		self.model = 'R2D2'
		self.color = 'gray'
		
my_robot = Robot()

my_robot.speed = 10
```

Так же атрибут можно удалить:
```python
del my_robot.speed
```
Даже тот, который был прописан в конструкторе
