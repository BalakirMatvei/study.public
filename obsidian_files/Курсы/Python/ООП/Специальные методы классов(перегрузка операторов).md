Эти методы интерпритатор вызывает автоматически в определенных случаях:
- создание/удаление объектов
- вызовы встроенных функций
- преобразование объектов(приведение типов)
- выполнение операторов языка
- эмуляция вызова функции
- работа с атрибутами объектов

такие методы выглядят как `__имя__()` 

```python
__init__(self, gift=None)
#инициализирует объект, присваивает ему атрибуты, может принимать еще параметры

__del__(self)
#выполняется перед удалением объекта(конец скрипта)

__str__(self)
#срабатывает при преобразовании объекта в строку(например при вызове print(object_name))
```
```python
def __str__(self):
	return "Backpack: " + ', '.join(self.content)
	
print(my_backpack)
#Backpack: book, apple
```
Аналогичные вызовы:
```python
print(str(my_backpack))

print(my_backpack.__str__())
```

```python
__len__(self)
#вызывается для получения "размера" объекта с помощью функции len()

__hash__(self)
#вызывается для получения уникального хэша объекта с помощью функции hash()

__bool__(self)
#вызывается для получения "истинности" объекта с помощью функции bool()
```

```python
if my_backpack:
	print('рюкзак не пуст')
else:
	print('рюкзак пуст')
```
Если метод `__bool__()` не определен в классе, то интерпритатор вызовет метод `__len__()`, если и его нет, то интерпритатор считает, что объект в любом случае `True`, тк он существует

Но без определенного метода `__len__()` выполнить код
```python
print(len(my_backpack))
```
не удастся(в отличии от `__bool__()`).

**Эмуляция вызова функции**
Объект можно использовать как функцию, для этого нужно определить в классе специальный метод
```python
class MyFunction:

	def __call__(self, *args, **kwargs):
		print(args, kwargs)#для примера	
```
Тогда можно сделать "объект-функцию"
```python
func = MyFunction()

#и вызвать его как функцию
func(1, b=2)#вызовется метод __call__()
```
Аналогичен вызов:
```python
MyFunction.__call__(func, 1, b=2)
```
