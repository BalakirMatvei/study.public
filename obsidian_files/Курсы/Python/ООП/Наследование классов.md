Наследование применяется там, где можно выделить общие свойства/поведение объектов класса.

Родительский класс при наследовании указывается в скобках
```python
class Pet:
	legs = 4
	has_tail = True
	
	def inspect(self):
		print(f"количество ног - {self.legs}\nхвост есть - {self.has_tail}")
	
class Dog(Pet):

	def sound(self):
		print("Гав")
```
При наследовании объект **подкласса** получает все атрибуты родительского класса и имеет доступ ко всем его методам.

```python
def inspect(self):
	print(self.__class__.__name__)
	print(self.__dict__)
```
1й print выведет имя класса, от которого создан объект
2й print выведет подкапотный словарь атрибутов объекта(**видны только те, которые определены через self, но не те, что были унаследованы от родительского класса**)

**Порядок поиска атрибутов объекта**: ^eb34a1
- Сам объект
- класс этого объекта
- родительский класс

Например:
```python
class Pet:
	legs = 4
	has_tail = True
	
	def inspect(self):
		print(f"количество ног - {self.legs}\nхвост есть - {self.has_tail}")
	
class Cat(Pet):

	def sound(self):
		print("Meow")
		
class Bobtail(Cat):
	has_tail = False
	
	
my_pet = Bobtail()
my_pet.inspect()
```
несмотря на то, что метод `inspect` опеределен в самом верхнем классе Pet, атрибут `has_tail` будет браться из самого нижнего класса `Bobtail`

Наследование не обязательно должно связывать похожие объекты, например:
```python
class CanFly:
	pass
	
class Butterfly(CanFly):
	pass
	
class Airplane(CanFly):
	pass
```
Бабочка и самолет вроде никак не связаны, но оба умеют летать и по этому свойству имеют общий родительский класс.
