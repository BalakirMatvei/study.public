инициализируется при помощи круглых скобок () или функции tuple()
```python
tup1 = ()
tup2 = tuple()
```
Кортеж, как и список, -  упорядоченный набор элементов с индексом, начинающимся с нуля.

После создания кортежа добавлять или удалять элементы нельзя(тк это неизменяемый тип данных)
Для взаимодействия с ним в таком плане нужно преобразовать его в список функцией list()

Что бы создать кортеж из одного элемента нужно поставить запятую в скобках
`tup1 = ("a", )`
Если этого не сделать, то вместо кортежа будет создана строка.

Если в `enumerate` спользовать не 2, а 1 переменную, то в ней будет кортеж, состоящий из индекса и элемента:
```python
lst = ["apple", "banana"]
for i in lst:
	print(i)
#(0, "apple")
#(1, "banana")
```
Аналогично со словарем и функцией .items()
```python
diction1 = {'огурцы': 2, 'помидоры': 3, 'лук': 1, 'картофель': 2}
for i in diction1.items():
	print(i)
#('огурцы', 2)
#('помидоры', 3)
#('лук', 1)
#('картофель', 2)	
```
