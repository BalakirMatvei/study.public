В функцию можно передать параметры не именуя их
```python
def example(x, y, z):
	return x**2 + y**2 + z**2

result = example(1, 2, 3)
print(result)
```
В таком случае будет производиться сопоставление
x = 1, y = 2, z = 3

Можно передать именованные параметры:
```python
def example(x, y, z):
	return x**2 + y**2 + z**2

result = example(x=1, y=2, z=3)
print(result)
```
Этот способ выгоднее когда у функции становится много параметров

Если передавать именованные параметры, то их порядок не важен
```python
def example(x, y, z):
	return x**2 + y**2 + z**2

result = example(z=3, x=1, y=2)
print(result)
```

Можно совмещать(**!при этом способе именованные параметры можно передавать только после указания ВСЕХ позиционных!**)
Правильный вариант:
```python
def example(x, y, z):
	return x**2 + y**2 + z**2

result = example(1, 2, z=3)
print(result)
```
Неправильный вариант:
```python
def example(x, y, z):
	return x**2 + y**2 + z**2

result = example(1, y=2, 3)
print(result)
```
Можно заставить передавать именованные параметры:
```python
def example(x, y, *, z):
	return x**2 + y**2 + z**2

result = example(1, 2, 3)
print(result)
```
Звездочка означает, что следующий после нее параметр должен быть передан как именованный(если передать звездочку на первом месте, то при вызове все параметры должны быть именованными)
