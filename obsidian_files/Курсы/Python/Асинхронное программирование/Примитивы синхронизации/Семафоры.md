Семафор построен на `Lock` 
****
Семафор хранится в модуле `threading`, хранит счетчик и ограничивает количество потоков, которые могут одновременно работать с объектом. 
****
- `acquire()` уменьшает счетчик семафора на 1 и пропускает поток(если счетчик больше 0), если счетчик равен 0, то следующие потоки ждут(заморожены).
- `relise()` увеличивает счетчик на 1 и "размораживает" один из ждущих потоков.
****
Лучше использовать в котекстном менеджере:
```python
import threading

sem = threading.Semaphore(3)#в скобках указано максимально количество потоков
ls = [1, 2, 3, 4, 5]

def some_func(n):
	with sem:
		ls.append(n)
		
threads = [threading.Thread(target=some_func, args=(i,)) for i in range(5)]
for t in threads:
	t.start()
for t in threads:
	t.join()
```

- Ограничить число одновременных запросов к `API`
- Ограничить число одновременных подключений к БД
