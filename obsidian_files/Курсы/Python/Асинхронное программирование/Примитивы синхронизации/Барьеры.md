Барьер хранится в модуле `threading`, знает сколько всего потоков должно собраться, каждый вызов `wait()` блокирует поток. Когда набирается нужное число, **все** потоки разом просыпаются
****
```python
bar = threading.Barrier(parties, action=None, timeout=None)
#parties - количество потоков, которые должны подойти к барьру
#action - функция, которую выполнит РОВНО 1 поток в момент срабатывания, до того, как все продолжат
#timeout - максимальное время ожидания барьера
bar.reset()#вернет в исходное состояние(ждущие потоки получат ошибку BrokenBarrierError)
bar.abort()#"сломать барьер", все текущие и будущие wait() упадут
```
****
Обработка поломки барьера:
```python
import threading
bar = threading.Barrier(3, timeout=2)

def func():
	try:
		bar.wait()
		print('все потоки дошли')
	except threading.BrokenBarrierError:
		print('кто-то не дошел')
		
for i in range(2):#запускаем только 2 потока из 3, что бы по таймауту сломать барьер
	threading.Thread(target=func).start()
```
****
Если какой то поток упал из-за ошибки, то остальные будут ждать его вечно, поэтому нужно задавать `timeout` или вызывать `abort()` в блоке `except`.
