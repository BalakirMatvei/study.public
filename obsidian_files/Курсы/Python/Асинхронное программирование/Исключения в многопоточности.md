Если мы хотим "отловить" исключения в потоках, то в блок `try except` нужно заключить все содержимое метода`run()`
```python
import time  
from threading import Thread  
  
class Worker(Thread):  
  
    def __init__(self, name, otdyx, *args, **kwargs):  
        super(Worker, self).__init__()  
        self.name = name  
        self.otdyx = otdyx  
  
    def run(self):  
	    try:
	        for i in range(1, 6):  
	            print(f'{self.name}:day {i}', flush=True) 
	            time.sleep(self.otdyx)  
	        print(f'{self.name} is done')
	    except Exception as e:  
		    print(e)
```
Но лучше будет выглядеть и читаться, если в методе `run()` будет только `try` ,вызов **метода**, `except`,  а в этот **метод** будет перенесен код из метода `run()`
```python
import time  
from threading import Thread  
  
class Worker(Thread):  
  
    def __init__(self, name, otdyx, *args, **kwargs):  
        super(Worker, self).__init__()  
        self.name = name  
        self.otdyx = otdyx  
  
    def run(self):  
	    try:
	        self._work()
	    except Exception as e:  
		    print(e)
		    
	def _work(self):
		for i in range(1, 6):  
	            print(f'{self.name}:day {i}', flush=True) 
	            time.sleep(self.otdyx)  
	        print(f'{self.name} is done')
```
