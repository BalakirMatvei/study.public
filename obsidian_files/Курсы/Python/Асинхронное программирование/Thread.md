Класс для управления потоками
```python
from threading import Thread
```
В поток можно задать выполнение какой либо функции:
```python
def some_func(arg1, arg2):
	pass
	
thread = Thread(target=some_func, kwargs=dict(arg1='hello', arg2='world'))

thread.start()
thread.join()
```
После `target` указывается функция, которую поручают потоку, дальше указываются аргументы, которые нужно в нее передать, можно передавать как позиционные, так и именованные:
```python
args=('hello', 'world')
kwargs=dict(arg1='hello', arg2='world')
```
****
```python
thread.start()
```
используется для начала работы потока

```python
thread.join()
```
Приостанавливает работу основного потока, что бы подождать окончание работы потока, у которого был вызван `.start()`

Принимает параметр `timeout`:
```python
thread.join(timeout=1)
```
принимает время в секундах, означает: "подожди поток столько то секунд, если он не успеет закончить работу, то иди дальше"
****
Обычный вызов функции выполняется в **основном потоке**
```python
func_name(arg1, arg2)
```
