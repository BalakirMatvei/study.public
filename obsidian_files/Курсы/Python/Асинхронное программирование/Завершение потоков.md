Извне поток завершить невозможно
И это правильно, т.к.
- поток в момент "завершения" может работать с файлами или другими структурами и это может разрушить их целостность
- Поток может порождать другие потоки, их тоже завершать?
****
Но можно добавить признак выхода:

У потоков есть метод `thread_name.is_alive()`, он проверяет выполняется ли еще поток.

```python
import time  
from threading import Thread  
  
class Worker(Thread):  
  
    def __init__(self, name, otdyx, *args, **kwargs):  
        super(Worker, self).__init__()  
        self.name = name  
        self.otdyx = otdyx
        self.need_stop = False  
  
    def run(self):  
        for i in range(1, 6):  
            print(f'{self.name}:     day {i}', flush=True) 
            time.sleep(self.otdyx)  
        print(f'{self.name} is done')
        if self.need_stop:
	        print('I need rest', flush = True)
	        break
```
Что бы этот "выход" работал нужно:
- запустить поток
- дать ему время на выполнение(иначе зачем было его запускать)
- если он еще запущен передать `True` в нужную переменную
- **обязательно** подождать завершение потока
```python
thread = Worker("Ivan", 0.5)
thread.start()
time.sleep(1)
if thread.is_alive():
	thread.need_stop = True
thread.join()
```
