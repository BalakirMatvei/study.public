Можно создать свой **класс**: который будет **наследоваться** от класса **`Thread`**, в методе `__init__()` прописать в `self` все параметры, а в методе `run()`прописать полезную нагрузку для потока
```python
import time  
from threading import Thread  
  
class Worker(Thread):  
  
    def __init__(self, name, otdyx, *args, **kwargs):  
        super(Worker, self).__init__()  
        self.name = name  
        self.otdyx = otdyx  
  
  
    def run(self):  
        for i in range(1, 6):  
            print(f'{self.name}:     day {i}', flush=True) 
            time.sleep(self.otdyx)  
        print(f'{self.name} is done')
```
Теперь что бы создать поток нужно создать объект этого класса:
```python
vanya = Worker('Vanya', 0.5)  
kolya = Worker('Kolya', 0.6)
```
Что бы запустить работу потоков нужно все так же написать:
```python
vanya.start()  
kolya.start()
```
А что бы подождать его завершения([[Thread#^515d43]])
```python
vanya.join()  
kolya.join()
```
****
В любой момент работы программы(до/после `start/join`) можно выполнять другие операции, они будут выполнятся основным потоком.
