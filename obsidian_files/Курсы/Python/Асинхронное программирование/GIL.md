**GIL**(Global Interpreter Lock) - механизм, который позволяет `python` выполнять код внутри одного процесса только одному потоку(даже если ядер несколько).

Он делает многопоточность практически бессмысленной.

**НО**
Там где есть операции ввода/вывода: чтение данных с диска, обмен данными по сети и т.д.  многопоточность оказывается полезна.

Любая программа должна общаться с внешним миром.
