Если функция вызывается в коде много раз и какой то параметр всегда(или почти) одинаков во всех вызовах, то его можно сделать параметром по умолчанию:
```python
def example(person, action='бегает')
	print(person, action)
	
example(person='Саша')#Саша бегает
example(person='Матвей', action='бегает')#Матвей бегает
example(person='Денис', action='едет')#Денис едет
```
Если в функцию при вызове не передали параметр, который задан по умолчанию, то в него будет передано значение по умолчанию.
Иначе в него будет передано значение, указанное при вызове функции. 

Если параметром по умолчанию задать пустой список:
```python
def element_to_add(element, list_to_add=[]):
	list_to_add.append(element)
	return list_to add
```
то при нескольких вызовах функции не будет каждый раз создаваться новый список, а будет каждый новый вызов работать один и тот же список, созданный при первом вызове функции
```python
new_list = element_to_add(element=1)
print(new_list)#[1]

other_new_list = element_to_add(element=7, new_list)
print(other_new_list)#[1, 7]

another_new_list = element_to_add(element=9)
print(another_new_list)#[1, 7, 9]
#хотя казалось бы, что должен быть вывод [9]

print(new_list is another_new_list)#True
#Это значит, что обе перемнные ссылаются на 1 и тот же объект, а это значит, что функция не создает новый пустой список при каждом вызове с параметром по умолчанию, а использует один и тот же объект для всех вызовов
```
