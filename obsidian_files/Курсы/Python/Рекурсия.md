Рекурсия - вызов функцией самой себя

В рекурсионной функции должен быть базовый случай(условие выхода из рекурсии) и рекурсионный случай(условие погружения на ступень ниже(вызова функцией самой себя))

Рассмотрим рекурсию на примере функции, считающей факториал
```python
def factorial(n):
	if n == 1:
		return 1
	factorial_n_minus_one = factorial(n=n-1)
	return n * factorial_n_minus_one
```
Блок кода if - базовый случай, все остальное - рекурсионный

**Если не указать базовый случай**, то запустится бесконечная рекурсия и **python выдаст ошибку** спустя определеное кол-во вызовов(около 1000(зависит от потребления памяти функцией))
