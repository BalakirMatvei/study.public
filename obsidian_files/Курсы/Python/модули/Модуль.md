**Модуль** - это **файл**, содержащий определения и выражения на python.
**Именем файла** является имя **имя модуля** с добавленным суффиксом **.py**.

Что бы иметь доступ к коду **модуля** из **другого модуля** его надо
**импортировать** 
`import module_name`
Это действие не переносит переменные и функции в текущее пространство имен, но к ним можно обратиться
`print(module_name.variable_name)`

По факту "module_name" - переменная 

Если импортировать модуль, в котором написан какой то код(например print('cheto tam')), то он выполнится при import 
**Пример**:
```python
#module1
variable1 = 7
variable1 = [1, 2, 3]

print('hello')
print("module name =", __name__)#возвращает имя модуля(если совпадает с текущим модулем, то возвращает __main__)
```
```python
#module2
import module1
```
Вывод при запуске module2:
```
hello
module name = module1
```

Что бы при импорте модуля он не выполнялся весь, а мы только брали из него нужное, то такую точку входа нужно обозначить:
```python
#module1
variable1 = 7
variable1 = [1, 2, 3]

if __name__ == '__main__':
	print('hello')
	print("module name =", __name__)
```
Так же это надо если модуль не только импортируется, но и иногда запускается сам, как скрипт
