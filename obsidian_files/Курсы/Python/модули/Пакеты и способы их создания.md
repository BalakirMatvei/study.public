Пакеты - способ структурирования пространств имен(namespaces) модулей python.

По сути пакет - папка файловой системы, в которой есть `__init__.py`. Все python модули относятся к пакету. 

**Импорт модуля из пакета**:
```python
from package_1 import module_1

module_1.function_1()
```
**Импорт конкретной функции/константы**:
```python
from package_1.module_1 import function_1

function_1()
```
**Другой способ импорта модуля**:
```python
import package_1.module_1

package_1.module_1.function_1()
```
Неудобно при множестве вызовов функции(много писать)
**Но можно сделать синоним**:
```python
import package_1.module_1 as p1m1

p1m1.function_1()
```
В папке пакета может лежать папка подпакета(в ней тоже должен быть файл `__init__.py`)

**Импорт из подпакета происходит почти так же**:
```python
from package_1.subpackage_1 import module_2

module_2.function_2()
```
Остальное по аналогии.

**Наиболее распространено**:
Если нужно конкретная функция, то импортируют именно ее в текущее пространство имен.
С модулем то же самое.

**Если какой-либо код лежит в файле `__init__.py`, то он импортируется напрямую из пакета**:
```python
#package1.__init__.py
def function_3(n):
	return n**2
	
	
#module_123
from package_1 import function_3

function_3(n=2)
```

**"Относительный импорт"**:
Если в пакете лежат "module_1" и "module_2"(на одном уровне файловой системы) и надо из одного во второй что то импортировать, то:
```python
from .module_2 import function_2

function_2()
```
Это пошло из линуска, где одна точка обозначает текущую директорию, а две точки - родительскую.
Соответсвенно из субпакета можно обратиться к модулю из пакета(на уровень выше)
```python
#package_1.subpackage_1.module_3
from ..module_2 import function_2

function_2()
```
