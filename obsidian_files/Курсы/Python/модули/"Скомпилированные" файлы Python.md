Эти "скомпилированные" файлы python идут с расширением ".pyc"

Если в каталоге "__pycache__", где хранится модуль с именем "module_name.py", хранится так же файл "module_name.pyc", предполагается, что это уже скомпилированная в байт-код("byte-complied") версия модуля "module_name".
В файле с расширением ".pyc" зафиксировано время изменения файла "module_name.py" версии, использовавшейся для создания "module_name.pyc". 
Если версии не совпадают, то файл ".pyc" игнорируется.
**Это используется для ускорения запуска программ** 

**Если файл запущен путем передачи его имени командной строке, то его байт-код не будет записан в файл ".pyc"** (они создаются только при импортах)

Что бы посмотреть этот байт-код нужно
- импортировать модуль дизассемблирования
```python
from dis import dis
```
- вызвать функцию dis() и передать в нее имя функции(без вызывающих скобок)
```python
dis(func_name)
```
В выводе будет байт-код(псевдо-код) функции
