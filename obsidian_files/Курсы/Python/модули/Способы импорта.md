**Простой импорт**
```python
import module_1
```
**Импорт всего модуля с другим именем**
```python
import module_1 as m1
```
**Импорт конкретного элемента**
```python
from module_1 import function1, variable1
```
Тогда к ним можно обращаться не `module_1.function1`, а просто `function1`

**Псевдонимы конкретным переменным/функциям**
```python
from module_1 import function1 as f1, variable1 as v1
```
**Импорт всех элементов**
```python
from module_1 import *
```
Для больших программ **не рекомендуется**, тк **имена** из текущего модуля и импортируемого модуля **могут перекрываться**
