Все импортируемые модули лежат в виде файлов(модулей) с расширением .py

Модули для импорта ищутся сначала в текущем каталоге, потом в каталогах, указанных в переменной окружения PYTHONPATH, затем в директории инсталяции python.

Все пакеты устанавливаемые из интернета(`pip install`) хранятся в папке `site-packages`.

В действительности, поиск модулей производится в списке каталогов, передающемся в `sys.path` из модуля `sys`

Импортировать можно не только на верхнем уровне, но и внутри функции
```python
def trigonometry(alpha):
	from math import sin
	return sin(alpha)
```
При этом функции. из модуля импортированные внутри функции остаются на локальном уровне переменных.

Под капотом импорт происходит 1(при первом вызове функции, в которой происходит импорт, дальше функция подгружает импортированный модуль из кэша) раз и хранится внутри пайтона, так что при множественном вызове замедления не происходит
