Можно вывести элемент по индексу и поместить его в переменную
```python
lst = [1, 2, 3, 4, 5]
number = lst[0]
```

можно присваивать несколько значений нескольким переменным(в том числе с помощью срезов)
```python
lst = [1, 2, 3, 4, 5]
num1, num2, num3 = lst[0], lst[2], lst[3]

num4, num5, num6 = lst[:3]
```
! Количество переменных должно быть равно количеству элементов среза !

Если нас интересует первый(последный элемен), и хотим что бы остальные лежали отдельно, то
```python
week = ['Mon', "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"]  
Mon, *days = week#в Mon лежит строка "Mon", в days все остальные элементы списка
Mon, *days, Sun = week
print(Mon)#"Mon"
print(days)#["Tue", "Wed", "Thu", "Fri", "Sat"]
print(Sun)#"Sun"
```
