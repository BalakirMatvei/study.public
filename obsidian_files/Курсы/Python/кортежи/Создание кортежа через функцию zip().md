Функция **zip()** принимает два и более списка и формирует объект из кортежей.
![[Pasted image 20261007203624.png]]
объект выглядит так:
![[Pasted image 20261007203731.png]]
Его нужно преобразовать в список:
```python
lst = list(zip(lst1, lst2))
print(lst)
#[(a1, a1), (b1, b2), (c1, c2)]
```
****
Если списки разной длинны, то длинна списка кортежей будет равна длинне меньшего списка(пары вида `(element, None)`образовываться не будут).
```python
nums1 = [3, 5, 7, 9, 11]  
nums2 = [2, 4, 6, 8]  
res = list(zip(nums1, nums2))  
print(res)
```
