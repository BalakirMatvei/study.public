При открытии в режиме чтения мы оказываемся на нулевой позиции(начало файла)

```python
f = open('file_name', mode='r', encoding='utf8')
file_content = f.read(100)#прочитать 100 символов и записать в переменную
print(file_content)
print(file.tell())#возвращает позицию в файле в байтах
file_content = f.read()#дочитывает файл до конца с текущей позиции
f.close()
```
Позиция, которую вернет функция `tell()` будет отличаться от количества прочитанных символов(тк `tell()` возвращает в байтах).

При повторном вызове функции `read()`, следующие символы не будут записаны в конец строки, хранящейся в переменной `file_content`, она будет перезаписана(обнулена и заполнена заново).
****
Что бы перемещаться по файлу используется метод `file_name.seek(offset, whence)`
```python
f = open('file_name', mode='r', encoding='utf8')
file_content = f.read(100)
file_name.seek(offset, whence)
file_content = f.read(100)
f.close()
```
`offset` - количество байтов на которые нужно передвинуться
`whence` - точка отсчета, может быть указана двумя способами
**Через число**
0 - начало файла
1 - текущая позиция
2 - конец файла
**С помощью модуля io**:
```python
import io

f = open('file_name', mode='r', encoding='utf8')
file_content = f.read(100)
file_name.seek(10, io.SEEK_SET)
```
`SEEK_SET` - начало файла(0)
`SEEK_CUR` - текущая позиция(1)
`SEEK_END` - конец файла(2)
