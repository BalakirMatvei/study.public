Что бы узнать код символа:
```python
print(ord('h'))
```
Что бы узнать что за символ по коду:
```python
print(chr(104))
```
Что бы узнать 16тиричного представление по коду:
```python
print(hex(104))
```
Т.е каждый символ имеет свой код, в пайтоне символы хранятся в кодах unicode.
**Юникод** (англ. **Unicode**) — это международный стандарт кодирования символов, который включает знаки почти всех письменных языков мира, а также математические знаки, нотную запись и эмодзи.

**Тип данных bytes**
Очень похож на str, но перед кавычками идет префикс b
```python
bb = b'\xd1\x84'
```
По сути это **неизменяемая** последовательность целых чисел, поддерживает те же операции, что и str.
```python
print(bb[0])#можно индексировать

print(bb.count(0xd1))#считать включения

print(b'he' + b'llo')#конкотенация
```
Вывод
```python
209
1
b'hello'
```

Для представления в двоичном виде используется функция bin
```python
print(bin(3))
#0b11
```

Латинские символы ASCII(код меньше 127) при выводе на терминал отображаются как символы, а не как коды

Так же есть изменяемый аналог байтов - bytearray
```python
ba = bytearray(b'hello')
ba[0] = 32#код пробела
print(ba)
#вывод:
#bytearray(b' ello')
```

Для преобразования байтов в строку и обратно есть 2 функции

Строка в байты:
```python
print('hello'.encode('utf-8'))
print('hello'.encode('utf-16'))  
print('hello'.encode('cp866'))
```
т.е. мы хотим **закодировать** коды юникода в нужное представление.

Байты в строку:
```python
print(b'\xd0\xbf\xd1\x80\xd0\xb8\xd0\xb2\xd0\xb5\xd1\x82'.decode('utf-8'))
print(b'\xff\xfe?\x04@\x048\x042\x045\x04B\x04'.decode('utf-16'))
print(b'\xaf\xe0\xa8\xa2\xa5\xe2'.decode('cp866'))
```

Что бы выбрать кодировку для документа нужно в одной из первых строк модуля написать комментарий:
```python
# -*- coding: utf-16 -*-
```
Если этого комментария нет, то предполагается utf-8
