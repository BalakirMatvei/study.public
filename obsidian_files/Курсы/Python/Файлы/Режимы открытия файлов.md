Файл - упорядоченная совокупность байтов, которая хранится на диске и/или занимает отдельную область внешней памяти.
****
**Файл можно открыть для чтения "r":**
```python
f = open('file_name', mode='r')
content = f.read()
f.close()
```
Этот блок кода открыл файл в режиме чтения, с помощью `.read()` сохранил содержимое файла в переменную и с помощью `.close()` закрыл файл.(как только файл перестает быть нужен его нужно закрывать)
При режиме обычного чтения можно указать еще и кодировку
```python
f = open('file_name', mode='r', encoding='utf8')
```
Тогда можно не прописывать декодирование, оно будет происходить сразу.
****
**Файл можно открыть для бинарного чтения** "rb":
Тогда все что поменяется в коде, это:
```python
f = open('file_name', mode='rb')
```
В переменную `content` будет сохранено байтовое представление файла(байт-коды вместо символов)
Байты можно декодировать:
```python
print(content.decode('utf8'))
```
****
В качестве имени файла может быть указан полный путь к файлу, если путь не указан, то файл ищется в рабочей директории скрипта.
****
**Файл можно открыть для записи** "w":
```python
f = open('file_name', mode='w', encoding='utf8')
content = 'Hello world!'
f.write(content)
f.close()
```
****
**Файл можно открыть для бинарной записи** "wb":
```python
f = open('file_name', mode='wb')
content = b'Hello world!'
f.write(content)
f.close()
```

__При открытии файла в режиме записи(или бинарной записи) файл обнуляется и в него с нуля записывается то, что мы передадим
Если файла на диске нет, то он будет создан пустой__ 
****
**Файл можно открыть для добавления в конец "a":
```python
f = open('file_name', mode='a', encoding='utf8')
content = 'Hello world!'
f.write(content)
f.close()
```

Аналогично с бинарным добавлением в конец(не указывается кодировка и в файл записывается строка в байтах)
****
**Режим чтения с записью "r+"**:
```python
f = open('file_name', mode='r+', encoding='utf8')
file_content = f.read()
new_content = 'Hello world!'
f.write(content)
f.close()
```
В этом режиме можно и читать, и добавлять в конец файла, 
**В этом режиме если файла нет на диске, то будет ошибка**
****
**Режим запись с чтением  "w+"**:
Немного отличается от предыдущего
```python
f = open('file_name', mode='w+', encoding='utf8')
file_content = f.read()
new_content = 'Hello world!'
f.write(content)
f.close()
```
Файл откроет для записи(все содержимое будет удалено), в него можно записывать новое и считывать
(по моему мнению бесполезный режим)

**Если файла нет на диске, то он будет создан
Если есть, то он обнулится** 

Файл можно перебирать циклом:
```python
f = open(file_name, 'r', 'utf8')
for line in f:
	print(line, end='')
```
В переменной лайн в каждой итерации цикла будет строка файла.
