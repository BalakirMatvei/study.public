Ключевое слово ***like*** позволяет записывать условия для поиска совпадений по определенному паттерну с использованием ***регулярных выражений*** 
```sql
select *
from table_name
where column_name like 'pattern'
```
Регулярные выражения:
% - любое количество любых символов(0, 1 и более)
__ - 1 любой символ

Примеры:
  `'A%', '_a%', '%a'` и так далее
